# 参考图选取与来源记录

## 选取顺序

- 用户指定的输入照片优先，不用图库照片替换其身份。制作公开示例时，先复用现有适用且来源清楚的参考照；已有虚构人物参考照可继续使用。
- 需要新增风景、人物、生活或旅行参考素材时，优先查 Pexels 和 Unsplash，Pixabay 作为补充。不默认重新生图；找不到合适且适用许可明确的素材时，再按已有授权使用本地 Codex imagegen。仅需风格参考时不要擅自将照片中的人物作为身份输入。
- Pexels：人物、生活场景、旅行、自然风景；Unsplash：风景、建筑、城市、氛围感人像；Pixabay：风景、人物、插画和矢量素材。
- 搜索可用 landscape、mountain、forest、ocean、sunset；portrait、lifestyle、asian people、couple、family；candid portrait、people outdoors。按具体主体、场景和构图缩小范围，不机械限定种族或外貌。

## 逐张核对

用户提供的平台许可摘要作为选站参考，不是逐张图片的权利证明。实际选图时打开图片详情页及当时有效的许可页，确认免费图库归属和当前用途；Unsplash+、付费素材、广告跳转和外部赞助内容不能当作普通免费图库。不能仅凭搜索结果缩略图或“免费商用”标签认定可以使用。

许可入口：
- [Pexels](https://www.pexels.com/legal-pages/license/)
- [Unsplash](https://unsplash.com/license)
- [Pixabay](https://pixabay.com/service/license-summary/)

核对修改、公开展示、独立转售、品牌/商标以及人物肖像等适用限制。可商用不等于可以暗示人物是拾作客户、使用者、推荐者或代言人；不把图库人物生成样片描述为真实客户案例。婚纱配对仅是创作示例，不暗示两位真实人物存在婚姻关系。用途相关权利无法确认时记为待核对并换用合适的虚构参考照，不自行声称获得模特或品牌授权。若当前许可要求署名，必须满足，不能因默认不展示来源而省略。

## 来源随素材保存

每张下载/复用的外部参考图在对应项目的素材清单中保存以下信息（优先复用现有清单结构）：
- 素材 ID、本地相对路径、SHA-256、类型/用途（身份输入、场景参考或风格参考）。
- 平台、图片详情页 URL、平台图片 ID、作者名字及作者主页 URL；未提供的字段留空并注明未知，不猜测。
- 原始图片 URL、下载时间；临时签名 URL 和会话信息不进入公开记录，不能只留 CDN 地址代替来源详情页。
- 许可名称、许可 URL、核查日期、核查状态（已核查/待核对）、与本次用途有关的限制及核查依据。下载时可将相关许可摘录或截图保存在项目记录中，不把平台许可等同于所有第三方权利均已解决。
- 是否经过裁切/修改，以及生成效果图与输入素材 ID 的对应关系、所用提示词和生成工具。图库原照标注为图库来源，生成输出标注为 AI 生成，不混淆。

素材上传到小程序时，来源记录也保留在项目持久清单或现有素材元数据中；默认不新增用户端展示。参考照片的来源与模板提示词来源分别记录，不因采用 Pexels 输入照片就把 GitHub/抖音模板来源改为 Pexels。

共享参考照库保存虚构人物和逐张核查来源许可的宠物、风景、建筑输入照片（风景/建筑由用户2026-10-28明确授权扩充）；其他外部图库素材放对应项目，不把生成效果图或真实图库人物混入库内。检索、复用不自动授权购买、付费生图或发布。

真实用户照片的授权和目录只保留在私有工作区，不随公开 skill 发布；不将一次用户声明扩展为其他真实人物素材的授权。
