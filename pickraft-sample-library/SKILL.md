# 拾作参考照库

公开仓库版本只包含检索规则和来源记录规范，不包含二进制参考照片、真实用户照片或本机私有 `catalog.json`。实际部署如果有授权的私有参考库，再读取其目录和照片；没有私有库时按 [参考图选取与来源记录](references/reference-sourcing.md) 选择或生成素材。

本库规则覆盖可复用的虚构人物参考照、用户明确授权的宝宝参考照和来源许可已核查的宠物、风景和建筑图库参考照，不收录生成效果图。需要示例人物、宠物、风景或建筑输入时，优先查部署环境提供的私有 `catalog.json` 并查看照片，符合要求直接复用。

- 私有 catalog 可以记录主体、标签、尺寸、来源和 SHA-256；外部图库照还应附摄影师、素材页面及许可核查记录。目录中的批次名只表示素材最初的项目批次，不限制复用场景。

## 新增参考图

需要新增参考素材时，读取 [参考图选取与来源记录](references/reference-sourcing.md)：优先 Pexels、Unsplash，Pixabay 补充，逐张核查并记录来源。已核查的宠物、风景和建筑参考照片可加入本库；其他外部素材保存到项目。

## 使用规则

1. 只复用符合主体要求的参考照片。用户指定真实照片时使用用户照片；婴儿、宠物、产品等不得以成年人物替代。
2. 新技能需要效果验证时，以参考照和该技能的提示词生成对应输出，且须已有生成授权。不要把旧婚纱图当成新技能的生成结果。
3. 效果图及其提示词留在各自项目，不加入本参考照库。新增人物参考照仅在现有照片不适用或用户明确要求时生成、归档。
4. 将使用的参考照复制到目标项目，记录素材 ID、哈希与对应的虚构/AI 生成或图库来源及许可信息，不覆盖库内原文件。素材复用不自动授权上传、发布或调用业务生图接口。

## 风景与建筑复用偏好

用户于2026-10-28要求扩充可商用风景、建筑素材。后续类似模板先按主体、构图、视角、清晰度和许可适用范围筛选，再从符合条件的素材中随机选用，避免总用同一张。记录所选素材ID及输入/效果配对；用户指定照片优先。仅保存参考照，不收录生成效果图。

## 宝宝参考照复用

真实用户宝宝照片只保留在授权私有参考库中，不随公开 skill 发布。后续宝宝相关场景需要样片时可在私有库中复用，用户指定照片优先；不得将真实用户照片标记为虚构人物或 AI 生成照片。

用户于2026-10-28要求增加宝宝参考照并随机使用。已新增4张虚构宝宝普通参考照（`reference-baby-fictional-20261028-1` 至 `-4`）。后续宝宝模板先筛选年龄、构图、姿态等符合输入要求的授权真实宝宝或虚构宝宝照片，再随机选取，避免总用同一张；用户指定照片优先。记录所选素材ID、哈希及输入/效果配对，效果图不加入参考照库。
