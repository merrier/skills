# 抖音：Ego 发布适配

目标为抖音或 Douyin 时读取。以下操作来自 2026-09-08 的实测；入口、限制和选择器需按当前页面复核。发布授权及浏览器控制权遵循主 skill。

## 范围、入口与素材

- 已验证：七张图片上传、独立指定封面、原生话题、网页草稿暂存及恢复、已有合集保留、地点、自主声明、配乐试听及恢复、定时提交，管理页显示「定时发布中」。新建合集、视频投稿、立即公开和删除作品未实测；不把图文流程直接套给视频。
- [抖音创作者中心](https://creator.douyin.com/) → 作品发布 → 发布图文。核对当前登录账号；不能把上次的昵称或抖音号当作本次登录证据。
- 实测标题上限 20 字、正文计数上限 1000；给出不同切入点的候选并沿用已确认文字，不静默截断。与小红书续发时可复用已确认的适配标题，不套用 B 站长标题格式。
- 上传入口实测支持 JPG/JPEG/PNG/WebP，不支持 GIF；单张不超过 50 MB，最多 35 张。页面推荐 3:4、4:3，不建议宽高比例超过 1:2；以当前提示为准，不因此默认裁切所有原片。
- 现有 3:4 封面可作为首图，后接整车、侧后方、座舱等实拍；同时在「封面设置」中指定封面并检查文字和车身完整。不要把多比例封面或发布截图当成相册原片，张数不固定为七张。

## 文本、话题与网页草稿

- 标题入口曾为 `input[placeholder="添加作品标题"]`，正文为可编辑区域；先定位当前真实编辑器再输入。原生话题需从搜索候选中选择，本次保存后仍存在独立 `[data-mention]` 节点；裸井号文字不证明关联成功。
- 本次把带 `\n` 的多段文本一次写入富文本后，恢复草稿出现了多余 `*`。使用真实键盘 Enter 分段输入后解决；保存并恢复核对正文，不能只看输入时的 DOM。DOM Range 改光标曾与编辑器状态不同步，局部修改优先真实键盘操作，避免破坏相邻文字和话题。
- 「暂存离开」会返回上传页，并出现「你还有上次未发布的图文，是否继续编辑？」；点「继续编辑」恢复。实测标题、正文、七张图片、封面、三个话题、合集、地点、声明、音乐及定时设置均保留。仅验证了同一浏览器恢复，不称为跨设备云草稿。
- 恢复后逐项读回，注意用户可能在审阅时调整了设置。已提交后管理页也可能显示「继续编辑」，需结合「定时发布中」判断，不能据此认定仍未提交。

## 按模型比例加入合集

抖音图文支持合集。若本次方案或本机配置 `platforms.douyin.collectionRule` 为 `model_scale`，按**模型的缩尺比例**归类，不是按封面的 3:4、9:16 等画幅归类。

1. 从已核实的产品资料、包装／底座标注或用户确认中确定比例。`1:43`、`1：43`、`1/43`、`1比43` 可视为同一比例。不要仅凭车型、厂牌或照片里的大小猜比例；资料冲突先核实。
2. 打开当前账号的「添加合集」并读取已有列表，按完整比例匹配，不能把 `1:4` 当成 `1:43`。结合合集用途筛选适合当前图文的项目；唯一明确的匹配直接选入，在最终预览显示模型比例、合集全名和集数，不重复询问确认。
3. 优先核实本机 `platforms.douyin.collections` 中当前比例对应的名称，再从实际列表查找；例如 1:64 只能选择经页面确认存在的 1:64 合集，不推断合集已经创建，也不把所有模型都放进 1:43 合集。用户确认的映射只写本机配置，不作为公开 skill 的固定名称。
4. 若本篇用户已明确选择了合集，优先保留；发现比例不符时说明差异，不静默覆盖其选择。若多个合集都匹配且用途无法区分，给出实际名称让用户选。没有匹配项时说明缺项，让用户决定新建及名称或本篇不加；可继续准备其他字段，不自行创建重复合集。
5. 比例不明或同一篇包含不同比例模型时，说明素材情况并确认归类方式，不按第一张图的比例强行归类。
6. 核对平台给出的集数／排序。新图文按当前合集及平台规则安排，续改保留已有顺序；本次实测「第1集」只是该篇设置，不能固化到后续帖子。保存恢复后再次核对合集和集数。

用户已选择此归类规则时，可在准备草稿时选择匹配的已有合集，最终提交仍遵循主 skill 的完整预览确认；本文件本身不授予发布权限。

## 地点、声明与配乐

- 本次地点「首钢园」及自主声明「内容为个人观点或见解」均已保存恢复；它们是本篇选择，不固化为所有帖子的默认。按实际来源、用户要求和平台当前说明选择声明；此页面本次未发现独立「原创声明」控件，不把自主声明称作已声明原创。
- 配乐按本篇选择，记录曲名、作者、版本和曲目时长。用户想沿用旧图文音乐时，可另开标签页查看自己的历史作品；不要改动旧帖。播放器不显示曲名时，可只读核对当前页面正常加载的作品音乐信息，不调用私有发布接口，也不保存登录凭证或原始网络日志。
- 音乐入口有同名标题和实际操作按钮，要点击能打开音乐库的「选择音乐／修改音乐」。搜索曲名后核对作者和时长；找不到时按作者搜索，滚动**音乐结果列表内部**加载后续项，不能把前一页没有结果当成全库没有。
- 本次旧图文使用 **SKYLINE — MIRBRO，02:35**。库里还存在 HMHK 的同名曲及 MIRBRO 的 **SKYLINE（剪辑版），00:39**，不可混用。用户指定同版本时，匹配标题、作者与时长；只有其他版本可用则说明差异，让用户选择，不静默替换。这首歌不是以后每篇的默认配乐。
- 在对应结果行点击「使用」，核对发布页曲名及预览中的作者，试听、暂存并恢复。恢复时显示 `00:00` 不一定是丢失音乐，可能尚未加载时长；本次点击试听后进度正常，暂停后显示完整 `02:35`。检查名称、作者、播放及恢复结果再判断，避免重复选曲。

## 定时提交与结果

- 实测定时范围为当前时间 2 小时后至 14 天内；按当前提示复核。选择「定时发布」后核对绝对日期、时间和时区；日期时间入口曾为 `input[placeholder="日期和时间"]`。已确认定时后，用户说「提交发布」仍按该定时安排执行，不改成立即发布。
- 最终按钮仍叫「发布」。完整预览及明确授权后只点击一次；「正在发布」表示请求处理中，等待结果，不重复点击。成功后本次进入 [作品管理](https://creator.douyin.com/creator-micro/content/manage)。
- 管理列表刚打开可能仍显示旧作品和旧总数，可搜索最终标题的独特片段，等待加载后用标题、封面和图片张数定位本篇。不能仅凭旧总数认定失败或重复提交。
- 本次卡片显示「定时发布中」及「定时: 2026年09月09日 18:18」，证明预约已收下，尚未公开；不将其表述为审核通过或已到点发布。仅看到跳转还不够，应保存本篇卡片的状态与时间证据。状态不明时先查管理页，不另建同内容投稿。
- 记录最终素材、账号、文案、模型比例与识别依据、合集全名／集数、地点、声明、配乐、可见范围、定时时区及管理页状态。有公开链接才记录公开链接，否则保留管理地址及核验截图；既有文件名沿用，历史草稿截图注明提交前版本。

以上定时提交流程于 2026-09-08 实测并核验。本地素材与发布记录不随公开 skill 分发；历史结果不代表后续账号、合集列表或到点公开状态，以后发布仍读取当前页面。
