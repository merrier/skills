# 玩具与车模封面

为汽车模型与其他玩具自媒体制作有实物依据的封面。默认采用简洁评测风格：主体突出、中文标题清晰、装饰克制。支持评测、介绍、纯图集三种内容类型；纯图集不自动加“评测”“开箱”等字样。

## 默认配置

- 输入：用户指定的图片文件夹，以及其中的 `模型信息.md`（如果存在）。
- 默认交付：五种比例，每种一张；用户指定部分比例时只生成指定项。
- 选图：先确定各画幅的构图需求，再分别选择主图、辅助图及使用区域；不预先固定一张主图套用全部比例。
- 文案：逐款给出 2–3 组不同内容角度的主副标题；本款文案获得确认后再出图，一次确认覆盖其全部比例。
- 风格：简洁评测；汽车模型默认采用下方的科技感标题与随涂装取色规则，用户可调整风格或提供参考封面。
- 输出：直接保存到各车型的源素材文件夹，按 `封面_9x16.png` 等比例命名；同次任务各比例保持一致的视觉语言。用户另指定目录或命名时按其要求。

| 比例 | 目标尺寸（宽 × 高） | 构图方向 |
|---|---|---|
| 9:16 | 1152 × 2048 | 竖屏；可选有纵深的单一主体，或将 2–3 个有信息差的真实角度上下组合，兼顾上下界面遮挡 |
| 3:4 | 1536 × 2048 | 竖版；可选整车加细节，或前脸为主、车尾为辅的双图，主次明确 |
| 1:1 | 2048 × 2048 | 方形；优先考虑轮廓集中的完整主体，如前侧三分之四视角，主体与标题各有清晰区域 |
| 16:9 | 2048 × 1152 | 横屏；可选完整正侧面或横向舒展的整车，标题放上方或侧方，依留白决定 |
| 4:3 | 2048 × 1536 | 横版；可选低机位侧前方或有纵深的整车视角，兼顾车头、轮圈与标题空间 |

这些是本 skill 的画布预设，不是各平台的官方上传规范。不要把某个平台与单一比例绑定。用户指定平台入口、文件大小上限或精确像素时，优先采用其要求；需要断言最新平台规格时查阅该平台官方资料。生成工具是否支持目标尺寸，以实际能力与输出检查为准。

构图方向是汽车模型的候选思路，不是固定模板；其他玩具按其轮廓与可展示细节调整。单图足够时就用单图，不为填满竖版而堆叠近似角度。

## 1. 读取素材与识别内容

1. 枚举指定文件夹的图片。排除隐藏目录（含 `.agents`、`.cover-work`）、`封面`、`封面_*`、水印原图备份、旧生成结果及临时预览，避免把衍生图当作新的原片。本素材库优先使用已经原位处理完成的图片。
2. 若指定根目录包含多个车型，而用户没有明确批量范围，先列出可选车型，请其指定；不要默认给整库全部出图。用户已指定批量范围时直接按范围处理。
3. 实际查看图片，不能只看文件名。图片多时先用联系表了解可用角度，再查看候选原图。记录清晰度、主体完整度、朝向、反光遮挡、留白及已有拼图的面板位置，形成供各画幅选择的素材池。
4. 阅读同目录 `模型信息.md`，核对实物、包装和铭牌。文件夹名只作线索；以可辨认的实物及本款资料核对车型，不能把误命名沿用到标题。区分模型厂牌与真车品牌、模型比例与画幅比例、真车年款与模型发售日期。底座年份不能直接推出车型代际或模型发售时间；“初代”“拉力”“限定”等表述需另有依据。无法核实时用已知年款、版本或可见外观表述。
5. 不同角度必须属于同一车型和版本；没有用户要求时，不混入别的涂装、比例或版本。盒装展示、开箱内容可以保留包装；不要为了“去盒”凭空重建被包装遮挡的结构。
6. 元数据中标为“待确认”“候选”“按系列推定”的内容，不升级为确定的封面卖点。价格、限量数、联名、展会年份需有对应本款的依据。缺少资料时省略这些卖点，不阻塞只依赖可见外观的封面。

### 按画幅分别选图

在提出封面方案时，为每个请求的比例列出一行：**画幅 → 源文件 → 使用区域／视角 → 主图与辅助图关系 → 文字位置 → 选择理由**。

- 先判断该画幅需要怎样的主体轮廓、朝向与标题留白，再从素材池选图。比较缩略图中主体是否足够大、重要部件是否完整、文字是否易读；不要先选“最好看的一张”，再让所有比例迁就它。
- 不要求五种比例必须使用五个不同文件。合适时可以复用同一照片；同一拼图中的不同面板也可以服务不同画幅，但需明确使用上、中、下哪一幅，并查看原图确认该面板是完整整车还是局部特写。不能把特写误记为整车，再让工具补造被截断的车身。用户明确要求全套共用主图时，遵循其要求。
- 多视角组合只选能补充信息的真实角度，明确主体与辅助图的大小关系。它们是同一件模型的多个摄影面板，不是同一物理场景中增加多件模型；不要生成素材里没有的机位。
- 整套通过主副标题、字体、配色和装饰语汇保持统一，视角、图片数量、主体位置与标题分行可以随画幅调整。
- 文案确认后可直接按选图表制作。用户仅调整选图或排版时，沿用已确认的主副标题，不重新发起文案确认。

## 2. 提出双标题并等待确认

先判断内容类型；不能从上下文判断是评测、介绍还是图集时，与标题一起询问。根据已确认事实与用户表达，通常提出 2–3 组主副标题供选择：

- **主标题**承担一个核心信息或观看理由，优先易读的短句。候选之间更换内容角度，不只替换颜色、车型和形容词；批量时参考前几款已选标题，避免连续重复句式或“锋芒、战衣、细看”等词。
- 可从配色反差、造型观察、可见细节、改装与原厂差异、收藏选择、桌面展示等角度发散。例如“如果拉法不穿红色”“从白轮圈到大尾翼”“这台 CGT，怎么有点不一样？”“给满柜超跑，换一口薄荷味”分别对应不同看点；只借鉴表达角度，不逐款套句。疑问句不能暗示未经证实的评测结论。
- **副标题**提供完整且已核实的产品信息，没有固定字数上限；优先厂牌／系列、模型比例、完整车型，再补充本款年款、版本、涂装或可见细节。可按“品牌与完整型号／年款版本与配色”分为两行，并随画幅继续换行。不为追求简短而删掉有辨识价值的信息，也不为凑字数写入推测。
- 评测结论必须来自用户或实际内容；照片不能证明手感、可动表现、漆面工艺水平、性价比或质量排名。
- 不凭空使用“全网首发”“最强”“必买”“限量 XX 台”“官方售价 XXX”等断言。图集可以突出颜色、造型和细节，不伪装成已经完成的体验结论。
- 未要求时不添加第三条口号、价格贴纸、账号名、创作者 Logo 或平台标志。确需额外文字，也应列入同一次文案确认。

先简要展示各画幅的选图与构图；确认卡聚焦当前一款的文件夹、内容类型、强调色和 2–3 组完整文案，以 A／B／C 标明不同角度。每个选项同时展示主标题和副标题，不能只让用户选一个角度名称。内容类型不要求必须出现在封面文字中，只使用确认后的文案。

**文案确认规则：**

- 必须取得对本次主标题和副标题的明确确认。用户只确认风格、比例或主标题时，副标题仍未确认。
- 用户在请求中明确写出“确认用以下主标题／副标题”可视为确认；仅提供候选文案时，先复述成组文案再确认。
- 本款主标题、副标题均确认前，不为本款调用图像生成工具，也不生成带暂定文字的封面。等待期间可以继续选图、核对事实、准备构图和制作其他已确认车型。
- 使用异步提问工具时，不因等待超时而视为同意。没有回答时保留待确认状态；独立工作做完后再交付进度与待确认文案。
- 一次确认覆盖同一车型的全部比例，无需逐比例重复询问。批量任务默认逐款询问，每款提供几个候选；上一款回复后再提出下一款，不把整批文案表要求一次确认。只有用户明确改为整批确认时才使用整批方式。
- 确认后保持字词、数字、大小写和标点一致；换行可随比例调整。若空间不足，先调整字号和排版；需要改字时才重新确认变更的文案。
- 用户选择候选并明确要求局部改字时，合并为最终文案，不重复确认已明确的修改。确认后若发现事实错误，简短说明实物依据并给出修正文案，只重新确认受影响车型；不要继续使用已知错误或静默改词。

### 批量执行与续做

在工作记录中按车型保存已确认主副标题、强调色、各比例源图与使用区域、目标路径和完成状态。收到回复就更新本款记录；每款合格后立即保存，不等整库全部生成完。续做时先读记录并核对文件，只处理未完成或确有缺陷的比例，不重复确认或重生成已完成项。用户修正选图时，同步更新选图记录和交付简报。

## 3. 生成多比例封面

使用当前环境提供的内置图像生成／编辑工具。调用前先查看所选本地图片；有本地路径时按工具规范传入参考图。不要仅为批量、尺寸控制或质量调整而静默切换到外部 API 脚本。用户明确指定本地排版、禁止重绘或选择其他工具时，遵循其已授权方式。

依据选图表，为每个比例传入对应的源照片，并在提示词中明确使用区域、视角和主体数量；不要把整个文件夹或所有画幅的素材一并交给工具自由选择。共享风格参考图只用于字体、层级与装饰风格，不能覆盖本画幅已选的实物视角、文案和本款强调色。

每个比例单独构图、单独生成文件，沿用同一组已确认文案、颜色和字体气质。不要把五种比例做进一张拼版，也不要通过拉伸同一张图适配全部比例。同一张封面内可以使用选图表中已安排的多个摄影面板。竖版和横版均以所选素材的朝向、轮廓和留白决定文字位置，不强制上下或左右分区。

### 科技感标题与强调色

- 汽车模型的中文主标题默认参考「优设标题黑」：宽扁、粗壮、轻微前倾与利落切角，兼顾速度感和缩略图辨识度。主标题中的英文车型或数字可参考「Orbitron Bold」的几何结构并适度突出；只强调已确认文案中的内容，不额外添加型号。副标题保持简洁无衬线字体。
- 中文主体文字按背景选高对比的中性色；车型强调文字与短装饰线默认共用一种强调色。强调色从本款车身主色或有辨识度的涂装色选取，不固定为红色，也不从背景、底座或反光中误取色。其他玩具同样依据实物配色调整。
- 原色与背景对比不足时，可调整强调色的明度、饱和度，或改取涂装中的次要颜色；黑、白、银等中性色车型可用与背景区分清楚的白、银灰或深灰，无需强行添加彩色。颜色调整仅用于文字和装饰，不改变实物颜色。
- 同一车型的多比例封面统一强调色；切换车型时重新取色。旧封面仅作风格参考时，不直接沿用其红色或其他强调色。短线可采用斜切端点，装饰保持克制。
- 提示词明确写出本次选定的文字色、强调色及其涂装来源。图像工具生成的近似字形应称为字体风格参考；只有实际使用对应字体文件排版时，才声称使用了该字体。

### 画面要求

- 主体依据实拍图；保留车型轮廓、轴距观感、轮圈、灯组、尾翼、车身颜色、涂装、车标、车牌和真实可见细节。不能把模型重绘成真车、改装成其他版本或消除评测中应呈现的瑕疵。
- 可使用克制的背景、留白、色块和光影承托主体；避免装饰覆盖重要实物细节。主色从实物涂装取色，中文采用清晰易读的字体，主副标题形成明显层级。
- 根据画面保留约 6%–8% 的边缘缓冲，作为设计起点而非平台安全区保证。整车主图保留车头、轮圈、尾翼等关键轮廓；有意选择的细节面板可局部展示，但所讲部位需完整可辨。所有新增文字不得被裁断；实际平台有遮挡示意时据其调整。
- 主标题、副标题和装饰线使用独立留白区域，不压在模型上；与车顶、后视镜、天线、尾翼等最高或外伸部件之间留出可见间隔。先按长副标题所需行数分配文字区，再安置模型。空间不足时调整留白、面板比例、主体位置或选图，避免把副标题缩得难读或覆盖车身；不要擅自删减已确认产品信息。
- 成图必须对应本画幅选定的照片区域、真实视角和主体数量；不要在所有比例中回退到同一主图，也不要生成素材中不存在的新视角。
- 默认保留已有摄影署名；本素材库明确保留 RossoGallery。署名保留在原照片内容中，不擅自改作账号名称、另加联名或放大为宣传标志；无署名的源片不因其他参考图带有署名而新增署名。默认不放创作者 Logo，包括此前已取消的“阿月模玩”Logo。

按下列要点编写每次生成提示词，无需把空字段也发给工具：

```text
交付：一张独立的 {比例} 汽车模型／玩具封面，目标 {宽} × {高}。
内容类型与风格：{评测／介绍／图集}；{确认的视觉风格}。
参考图片：{本画幅主图路径、使用区域与真实视角；必要的辅助图路径及角色}。
摄影面板：{数量、上下／左右顺序、主次大小；不使用的源图区域}。
主体：{已核实的车型或玩具名称、可见外观}。
构图：{适合本比例的主体位置、留白和文字区域；预留副标题行数，文字及短线与模型轮廓保持间隔}。
主标题，逐字照排：『{已确认主标题}』。
副标题，逐字照排：『{已确认副标题}』。
字体与配色：{中文标题、车型英文数字及副标题的字体方向}；主体文字色 {颜色}；车型强调文字与短线共用 {强调色}，取自 {本款实物的主色／涂装色，或对比度调整依据}。
只允许按排版需要换行，不改字、不添加未经确认的文字。
保留：{原片可见的关键结构、配色、涂装、标识和应保留署名}。
避免：主体变形、镜像朝向、虚构视角或细节、把模型变成真车、文字错漏或遮挡模型、未经安排的车辆复制、裁断主体、额外 Logo 或署名。
```

检查实际输出，不把提示词中的尺寸当作已实现的结果。仅有像素取整导致的微小比例偏差、且用户未要求精确尺寸时，保留工具原生文件，在简报记录实际尺寸与比例偏差，不反复生成只为追赶预设像素。明显错误的横竖画幅需要修正。用户要求精确像素但工具不支持时说明限制；已明确授权本地排版或尺寸后处理的，按其要求完成导出，否则提出具体处理方式，不静默拉伸或裁切。

## 4. 检查与交付

对每张图逐一检查：

- 实际像素尺寸与目标画幅；可用只读脚本读取尺寸，比例按宽高交叉乘积验证。
- 主副标题逐字一致，含英文型号、数字、标点；OCR 只作辅助，仍需查看成图。
- 对照选图表检查各画幅的源图区域、实际视角、主次关系与摄影面板数量，确保差异来自有意选图和排版。
- 与原片对照车头朝向、关键部件、颜色、标志、涂装和署名，不能仅凭整体“像”就通过。修正文字、强调色或短线后仍需复查实物，防止工具连带改变车身色块、镜像车辆或增删细节。
- 完整画面及手机缩略图大小下，主体可辨、主标题可读、副标题有清晰层级，且无文字遮挡重要细节。
- 强调文字与短线配色协调、对比清楚，取色对应本款实物；没有误沿用其他车型参考封面的颜色。
- 所有请求的比例各有独立文件；没有误用备份、其他车型或未经确认的文案。

有缺陷时仅修复受影响的版本，明确允许修改的文字或区域，其余保持原样；必要时同时提供待修图和原片，并说明原片只用于恢复实物细节。每次修复后重新检查；若相同缺陷持续出现且没有可行调整，记录未完成原因并告知用户，不无限重复生成，也不把有明显错误的版本标成最终稿。

将合格结果复制到各车型素材目录，保留工具原始输出、源照片和旧封面子目录：

```text
<车型素材文件夹>/
  封面_9x16.png
  封面_3x4.png
  封面_1x1.png
  封面_16x9.png
  封面_4x3.png
  封面简报.md
```

默认使用 PNG；工具返回其他格式时不要只改扩展名，按实际格式保存，或在用户已选择的处理方式中正确转换。只交付用户要求的比例和格式，不额外产生全套重复文件。同名结果已完成且合格时直接复用；用户已要求重做或替换时，检查新图合格后替换对应封面。若同名文件与本次任务的关系不明，先保留已有文件并确认替换范围。

保存后检查图片可解码、实际尺寸、比例命名及每款文件数；复制文件时可比对哈希，确认交付文件与检查过的成图一致。批量任务在根目录维护 `封面制作进度.md`，记录每款已完成比例、待确认文案或未解决问题；按实际文件报告完成数，不把待确认或仅发起生成的项目算入完成。

`封面简报.md` 简要保存各画幅的源图片链接、使用区域、构图、内容类型、确认后的主副标题、统一风格（含字体方向、强调色及取色依据）、各文件实际尺寸、使用的工具及最终提示词。存在未完成的比例或尚未解决的问题时明确记录。不要自动发布到平台。

完成后展示各比例预览并给出本地文件链接；报告实际完成数量及必要限制。仅创建或修改此 skill 时，执行结构校验即可，不为了演示而跳过文案确认生成封面。
