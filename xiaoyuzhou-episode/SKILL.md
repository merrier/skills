# 小宇宙单集

本 skill 借鉴 [xyz-dl](https://github.com/shiquda/xyz-dl) 的单集处理能力，只处理用户指定的一期。用户先问单集、随后说“下载这一期字幕”或“总结这一期”时，沿用已经核实的单集链接。

1. 按节目名、期数或用户给的链接定位单集。优先核对小宇宙单集页和制作方页面；确认节目名与期数同时匹配，避免把其他播客的同号单集当成目标。回复标题、嘉宾或主持（页面有写才填）、发布日期、时长、单集网页链接；缺失字段直说未找到。若同一期有多个候选，列出区别再请用户选择。
2. 用户要求“下载字幕/文字稿”时，先找该集公开且可实际获取的完整字幕或逐字稿。保存为 UTF-8 `.txt`；只有原文包含可靠时间码时才另存 `.srt`。文件名含播客名和期数，保存到用户指定目录；未指定时放到当前工作区之外的 `~/Downloads/播客字幕/`，回复绝对路径、来源链接和“官方字幕/第三方转录/自动转录”的类型。下载后检查文件非空且内容对应目标单集。节目简介、Show Notes、摘要和时间轴不能冒充完整字幕。
3. 如果公开来源没有完整文字稿，可在本机已有可用转录工具时，从该集公开音频生成自动转录，明确标注为自动转录并提醒可能有识别错误；避免为了转录而自动安装大模型或调用收费服务。若无法取得文字稿或转录音频，说明具体卡点并给出可继续的选择，不要声称下载成功。
4. 用户要求总结时，优先基于已取得的完整文字稿；若只有官方 Show Notes 或节目简介，可立即给出明确标为“基于节目简介/时间轴”的概要，并说明覆盖范围。不要把第三方摘要写成原节目逐字内容。重要观点尽可能给时间点或出处链接。把总结保存为 UTF-8 Markdown 文件：用户当次指定目录时放在那里，否则放在当次工作目录；文件名包含播客名和期数，回复中给出绝对路径。若目标目录有 `AGENTS.md` 等本地规则，保存前遵守其目录、frontmatter 和链接约定。

`xyz-dl` 当前 README 明确说明：免登录仅保证公开单集音频下载，字幕和部分元数据接口依赖登录态，且登录态下载可能触发账号风控。因此不要主动索取、保存、读取或使用小宇宙 token/device ID，不要调用登录接口、批量抓取或绕过付费/私有内容。只有用户明确要求使用其已配置的登录能力时，再核对项目当前说明和实际参数；仍需如实报告字幕接口是否成功。
