# 模型资料整理

为用户指定的模型建立一份可追溯的 `模型信息.md`。照片负责识别本件实物，检索补充产品资料；先匹配具体版本，再逐字段判断证据是否足够。不把搜索摘要、旧文案或相似款的参数直接当成本款事实。

## 输入与范围

- 沿用用户已选的素材文件夹；批量时每款单独整理，不合并不同车型、配色或比例。范围不清时先盘点候选目录，再确认需要处理的款式。
- 先读已有 `模型信息.md` 及用户补充。封面简报、发布稿和文件夹名只作线索，不能作为独立产品证据。
- 排除生成封面、操作截图、缓存、备份和旧生成目录。查看原片、盒标、底座及证书；联系表与 OCR 可辅助定位，关键文字仍回看原图。
- 输出仅为资料文件；整理资料不自动去水印、重做封面或发布内容。源照片保持不变。

## 1. 从实物建立候选身份

记录模型厂牌、系列、完整车型、车身与内饰颜色、涂装标识，以及包装／底座上可辨认的货号、比例和限量文字。为每项观察保留原文件名与位置，例如「盒标右下角」「底座正面」。

- 区分模型厂牌与真车品牌、模型比例与图片画幅、真车年款与模型发售日期。
- 货号保留原始写法。`O/0`、`I/1` 等模糊字符可作为搜索变体；在找到匹配证据前不要静默纠正原文或认定货号。
- 同文件夹可能有不同产品，外盒也可能不对应实物；核对车型、轮圈、涂装、内饰及底座。身份不一致时保留候选，不强行合并；影响本款识别时向用户确认。
- 「碳纹」「黑碳」等外观描述不能证明模型使用碳纤维；反光不能证明电镀工艺；按品牌常见材质、系列或货号前缀推定的比例与材质仍为待核实。
- 摄影署名（如 RossoGallery）不等于联名关系；普通真车品牌授权不自动记为特别联名。底座的个体编号与限量总数分别记录；通用的 `1 of N pcs` 铭文通常表示「N 件之一」，不能单凭它认定本件为第 1 号。

## 2. 检索与核对原文

优先使用已安装的 `anysearch` skill：从当前技能目录定位并读取其 `SKILL.md`，按该版本的运行配置和接口调用。复用它的搜索、批量检索及正文提取能力，不在本 skill 内复制 CLI、硬编码服务接口或维护密钥。未安装或不可用时说明实际情况，按用户允许的工具范围用现有网页搜索继续；不为此自动注册账号、购买额度或安装依赖。不要把「普通搜索完成」报告成「AnySearch 实测通过」。

搜索只需要公开的品牌、货号、车型和涂装文字，不上传整个素材文件夹、私密记录或照片。需要另行使用以图搜图时，先确认用户允许的服务与素材范围。

按问题组织少量检索，通常可批量执行相互独立的查询：

1. **精确身份：** 厂牌 + 完整货号；无货号时用完整车型 + 涂装／版本／比例。
2. **版本细节：** 中英文名称、包装拼写、限定活动名称；模糊货号单独测试字符变体。
3. **缺失字段：** 已匹配的货号 + 官方发售价／发布公告／限量数量等目标字段，不泛搜同名真车参数。

垂直搜索先按 AnySearch 当前规则发现可用分类，不能假定有车模数据库或特定社交平台接口。一般商品信息可用通用搜索；社交平台结果作为补充线索。返回实际平台与请求分类不符时如实记录，不宣称该平台检索成功。

打开有价值结果的原文；核对货号、厂牌、比例、颜色及版本。没有货号时，需要足以区分近似款的文字与图片细节，不仅凭同名车型匹配。摘要找到关键字但原文不可读、或原文没有相应内容时，保留为检索线索，不升级为已核实。

证据按字段选用：本件包装／底座可支持其明确标注的信息；品牌产品页、官方公告、展会或联名方公告可支持对应版本和发售事实；明确匹配货号的专业经销商页面可辅助核对比例、材质等。商家、收藏者帖子与二手平台不能仅因排名靠前就替代官方发售证据。多站复制同一文案不算独立交叉验证。

已有资料足够时不反复全网重查，只补缺项或处理冲突。更换关键词后仍没有匹配的新证据，就记录已查范围与待核实项，继续完成可确认部分；无需为凑齐字段无限搜索。

## 3. 逐项定论

使用四种状态：**已核实、用户提供、待核实、有冲突**。用户提供的信息保留来源，后续取得独立证据再改为已核实；用户选定某条标题不等于其产品事实已核实。

| 字段 | 判断规则 |
|---|---|
| 品牌／系列／货号／比例 | 精确到本款；品牌惯例和货号前缀只能作候选依据 |
| 材质 | 明确车身主体材质；混合材料按部件记录。原文 `die-cast` 不自动扩写成特定金属成分，树脂也不等于合金 |
| 车型与涂装 | 保留正式型号、真车年款／版本、官方色名；照片可见色与官方涂装名称分清 |
| 官方发售价 | 默认按官方首发口径，记录金额、原币种、市场／渠道及含税口径（已知时）；零售现价、划线原价、预售价、二手价或用户入手价分开记录，不直接当作官方发售价，也不自动换算成人民币 |
| 是否限量／数量 | 记录限定范围与总数，如「本配色 299 台」。不能套用同车其他颜色、其他比例、再版或整个系列的数量；个体编号不能当作总量 |
| 联名／限定属性 | 明确合作方、活动／地区／渠道和具体版本依据；普通授权、摄影署名、商家昵称和文件夹中的「限定」不能单独证明 |
| 发售时间 | 区分公告、预售、实际首发、补货及再版，标明市场。真车年款、网页更新日、帖子日期、底座年份不能直接填成首发日；证据只到年或月就保留该精度 |

没有找到限量、联名或限定资料时写「待核实」，不是「否」「无」或「不限量」。来源冲突时保留各自主张及其范围，优先检查是否为不同版本、市场或发售阶段，不平均价格、不任选日期。对影响身份、比例或当前文案的关键冲突向用户说明；其他缺项不阻塞成文。

## 4. 保存与复用

按 [资料模板](assets/model-info-template.md) 在**本款素材文件夹**保存 `模型信息.md`，模板字段按已查情况填写。核心字段即使未知也保留状态；来源编号逐项对应，记录本地照片的位置或网页的标题、URL、实际查阅日期，以及它支持和不能支持的内容。正文仅保留必要摘要，不复制整页商品文案。

已有资料优先按字段更新，保留用户笔记、入手价、出处及仍有效的已核实信息；不要用模板整页覆盖旧文件。旧文档写有「同系列推定」「候选」「待确认」时沿用其不确定性。新增证据推翻旧事实时，记录更正原因和受影响字段。缺乏来源的旧确定值先核验，不能因以前写过就自动继承为已核实。

文档提供一段只含已核实信息的「可直接用于文案的产品介绍」，另列用户提供信息与待核实项。身份尚未确定时不拼成完整确定的产品介绍。所有结论仍受原文和实物约束，照片无法证明手感、耐久、可动表现或性价比。

- `toy-cover` 与 `ego-publish` 优先读这份资料，避免各自重新猜产品参数；仅需要外观文案时，不因非必要字段未知阻塞任务。
- 产品资料与创作文案分开。封面主副标题仍由 `toy-cover` 逐款提供候选并确认；发布时间、正文、地点、音乐及平台提交仍走 `ego-publish` 的统一确认流程。
- 资料更新不自动修改已确认文案、生成封面或已发帖子。若修正的事实出现在待使用文案中，只提出受影响文字的修正并确认。

交付前回读文件，确认来源链接与本地照片存在、状态和介绍一致、没有混用不同版本的字段、官方发售价与真车年款未被错误填充。交付文件链接、主要确认结果和剩余缺项即可；单纯整理资料不需要逐字段索要用户确认。
