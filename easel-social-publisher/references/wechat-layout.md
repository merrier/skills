# 公众号留白禅意排版规则

微信公众号正文默认使用 Easel `gzh-design` 的「留白禅意风（zen-whitespace）」组件库。封面主题独立决定；正文使用留白禅意风不要求封面改成墨绿色。

用户当次指定其他主题、参考图或不需要排版时，当前请求优先。没有完整 Easel 或 `gzh-design` 组件库时说明限制，不凭记忆伪造主题组件。

## 1. 固定视觉参数

- 全局背景：纯白 `#FFFFFF`。
- 正文：`15px`、`1.9` 行高、`#525252`、两端对齐、左右 `16px`、段后 `26px`。
- 章节中文标题：衬线字体方向、`22px`、`#2B2B2B`、字重 `700`。
- 章节英文标签与短线：墨绿 `#4A5D52`。
- 正文关键词下划线：`1.5px solid #B5C8BC`，字重 `500`。
- 辅助文字：`#A3A3A3`。
- 分隔线：`#E8E8E8`，依靠留白而非色块分章。
- 图片：`max-width:100%;height:auto;display:block;margin:0 auto`，不强制拉伸小图。

公众号平台的文章主标题由微信客户端渲染，不在正文 HTML 中重复标题或设置标题颜色。

## 2. 用户确认的克制变体

在 `gzh-design` 原始留白禅意主题基础上固定以下调整：

- 章节使用连续两位编号，例如 `01`、`02`、`03`、`04`。
- 最后一章继续使用普通编号，不使用 `∞ · POSTSCRIPT`。
- 英文标签应直接对应章节含义，例如 `04 · TEN YEARS`；不确定时使用编号加简短直译，不造抽象口号。
- 默认不生成目录导读。
- 原文没有开头引用时，不新增引言卡。
- 正文粘贴完成后，默认在最前面插入公众号后台原生“账号名片”；账号从个人配置或当前已确认账号读取，不在 HTML 中仿制名片。
- 文章结尾默认生成“关于我”，内容读取个人配置中的已确认介绍；配置缺失时先询问，不使用通用占位或凭账号简介扩写。
- 默认不生成点赞／在看／转发 CTA。
- 不新增正文结论、营销文案或主题升华。
- 可以保留极简 `END` 分隔线；用户不需要时删除。
- 每段最多选择 1 个真正关键的短语加低饱和下划线。原文已经加粗的句子保留加粗，不再叠加下划线。

这些调整只改变排版和阅读层级，不改写、精简或重排正文。

## 3. 组件装配

1. 读取 `$EASEL_ROOT/skills/builtin/gzh-design/references/theme-index.md`。
2. 读取 `theme-zen-whitespace.md` 和 `common-components.md`，HTML 从组件库取，不跨主题混用。
3. 保留全部正文段落、原始章节、加粗和图片；图片用途继续遵守公众号正文图片与封面图片区分规则。
4. 根据 `##` 顺序生成连续章节编号和简短英文标签。
5. 输出纯 `<section>…</section>` 正文片段，不包含 `html`、`head`、`body`、`style` 或 `script`。
6. 所有样式内联，所有文字节点用 `<span leaf="">` 包裹。
7. 账号名片属于微信编辑器原生节点，不写进干净 HTML。粘贴并校验 HTML 后，把编辑器选区明确移动到正文最前面，再用工具栏“账号名片”插入精确账号；插入后核对名片位于第一章之前且全文只有一张。

## 4. 校验与预览

生成后必须运行：

```bash
python3 "$EASEL_ROOT/skills/builtin/gzh-design/scripts/validate_gzh_html.py" /absolute/path/article.html
```

ERROR 和 WARNING 都清零后，再运行 `wrap_preview.py` 生成带复制按钮的预览页。交付干净 HTML、预览页和校验结果。

粘贴到公众号编辑器后再次核对：

- 标题、作者、摘要、封面、原创和合集没有变化。
- 账号名片位于正文第一项，昵称与本次账号一致。
- 章节数量、编号和正文段落完整。
- 末尾正文图片仍在正确位置。
- “关于我”内容来自个人配置，位于正文和图片之后；没有额外 CTA。
- 关键词下划线没有覆盖整段或过密。
- 微信编辑器字数、首段和末段与源稿一致。

用户只要求预览时停在编辑器，不点击“发表”；编辑器自动保存属于草稿更新，不代表授权群发。
