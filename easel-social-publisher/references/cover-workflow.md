# 发布封面工作流

目标是为本次发布提供清楚、可复用、经过确认的封面或首图。封面是发布前阶段，不扩大用户已经授权的平台、内容或素材范围。

文章封面先按[封面制作前的文章处理](content-adaptation.md#封面制作前的文章处理)读取最新源稿，取用已确认的标题和正文，再判断画幅与构图。

## 1. 判断是否需要制作

先读取目标 publisher 的当前要求，再检查任务是否已有合格封面。

- 有合格封面且画幅、文字、授权和清晰度满足本次平台时直接复用。
- 平台不需要封面、用户明确不要封面或正文首图已经承担封面作用时跳过。
- 缺少封面、画幅不符或用户要求统一视觉时才制作。

以下尺寸是通用制作预设，不冒充平台最新官方限制。用户指定精确规格时优先使用；需要断言最新要求时检查平台当前页面或官方资料。

| 用途 | 工作预设 | 常见使用方式 |
| --- | --- | --- |
| 竖版首图 | 1080 × 1440，3:4 | 小红书首图与抖音文章封面共用设计稿 |
| 竖屏视频封面 | 1152 × 2048，9:16 | 抖音、快手、视频号竖屏视频 |
| 抖音文章头图／封面 | 1080 × 1440，3:4 | 抖音纯文章；分别检查首页推荐和双列封面 |
| 横版封面 | 2048 × 1152，16:9 | B站视频或明确要求的横版内容 |
| 公众号封面 | 900 × 383，约 2.35:1 | 公众号文章主封面 |
| 方形备用 | 2048 × 2048，1:1 | 头像式首图或平台裁切备用 |

只交付目标平台真正需要的规格，不默认生成全套。

抖音文章不得直接复用公众号或 B站的 16:9 横版封面。移动端会把横图放进竖向区域并居中放大裁切，容易切掉侧边标题和人物。默认制作 3:4；页面实时预览与本表冲突时以页面为准。

## 2. 确认输入

制作前一次确认以下信息：

- 目标平台与内容形态。
- 主标题和副标题的逐字文本；只有主标题时明确副标题为空。
- 原图、人物、Logo、赛事图、截图及字体的使用权。
- 哪些人物、产品、文字、水印和署名必须保留。
- 是否允许生成新背景、裁切原图、去除原图文字或改变人物与产品外观。
- 复用已有主题，还是建立一个命名的新主题。

用户已经明确给出且确认过的内容不重复追问。发现事实错误、授权不明或标题超过安全区域时，只重新确认受影响项。

## 3. 选择制作方式

优先采用最小且稳定的方式：

1. 原图加确定性排版已经足够时，不调用图片生成工具。
2. 缺少背景、装饰或氛围时，可用宿主 ImageGen 生成无人物、无文字、无 Logo 的背景，再与授权原图组合。
3. 用户明确要求重绘、风格转换或生成新视觉时，按宿主 `imagegen` Skill 使用图片生成或编辑工具。
4. 中文标题、数字、型号和署名使用 HTML/CSS、Canvas、SVG 或其他确定性排版。不要依赖图片模型生成需要逐字准确的中文。
5. 人物、商品、模型、Logo 和赛事奖杯需要保持真实时，优先保留原图；未经允许不让生成模型重画身份或产品细节。

不要为了尺寸控制静默切换到需要 API Key 的外部脚本。宿主工具不可用时说明限制，等待用户选择替代方案。

## 4. 建立或复用主题

后续图文默认沿用《写在 BLG 夺冠后，我和英雄联盟的故事》的封面与分页卡片版式。每篇根据主题选择主图和主色，同篇跨平台沿用同一套配色。例如电竞回忆用蓝青，校园回忆用黑板墨绿。

- 公众号、B站横版封面在左侧深色渐变上排粗体白标题和金色短线，右侧留给主图。公众号正文继续使用「留白禅意」。
- 小红书与抖音共用一份 3:4 竖版设计稿，上图下文，标题逐字采用已确认的完整文章标题。小红书多页卡片使用深底浅字、细框、栏目角标和右下页码；抖音封面从同稿隐藏页码后单独导出。
- 预览时将新封面和代表性内页与 BLG 母版并排核对；再检查同篇各平台的标题、构图和配色。

需要后续复用时，在用户指定的工作目录维护主题文件，例如：

```text
themes/<theme-slug>/
  THEME.md
  background.png        # 可选，且必须有来源与授权说明
```

`THEME.md` 至少记录：

- 主题名称和适用内容。
- 主色、背景色、强调色和文字色。
- 标题、副标题、署名和页码的字体方向与层级。
- 封面构图、边缘缓冲和安全区域。
- 原图、生成背景和模板资产的来源及可复用边界。
- 各规格允许改变的布局和必须保持一致的视觉语言。

主题放在任务工作区或用户指定的个人资源目录，不把生成图、个人照片、账号名或发布记录提交到公开 Skill 仓库。

## 5. 制作与检查

每个规格独立排版，不拉伸同一张成图硬套全部画幅。可以复用同一原图，但要根据构图重新安排裁切、文字和留白。

逐张检查：

- 文件可以解码，实际尺寸和比例符合本次计划。
- 主副标题逐字一致，无乱码、漏字、错误换行和孤字成行。
- 手机缩略图下主标题可读，主体仍可辨。
- 人物脸部、产品轮廓、Logo、奖杯和必要署名没有被错误裁切、重绘或遮挡。
- 文字与主体之间有清楚间隔，四周保留约 6% 到 8% 的设计缓冲；平台有明确遮挡区时按当前页面调整。
- 没有未经确认的新 Logo、平台标志、口号、水印、虚构人物或产品细节。
- 原图与生成背景的来源、工具和最终提示词已记录。

抖音文章额外检查：

- 文章头图和封面是两个独立槽位，不因可以“同步头图为封面”就默认共用。
- 只有同一张 3:4 图片在“首页推荐”和“双列封面”预览中都完整时才允许共用；任一预览裁切关键内容时分别制作。
- 关键人物、奖杯和视觉主体放在中央约 70% 安全区，左右边缘不放标题或关键人物。
- 底部预留平台标题和渐变遮罩区域。
- 双列封面保留完整标题。首页推荐叠加平台标题时，头图单独使用同主题无字主图，并复查两个槽位；头图与封面均去掉页码。

发现问题时只修受影响规格。连续两次无法修正同一问题时停止，说明限制，不把有明显缺陷的图片标成最终稿。

## 6. 预览与发布确认

封面制作完成后展示每种目标规格，给出本地绝对路径、实际尺寸、主题名和使用平台。用户确认封面后再进入上传或发布预检。

修改封面不撤销或扩大原有发布授权。封面文字、原图、画幅或主题发生实质变化时，需要重新展示受影响规格；只修复编码、导出或无视觉影响的元数据时无需重复确认。
